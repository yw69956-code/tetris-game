# 俄罗斯方块

在浏览器里玩的经典俄罗斯方块。10×20 棋盘、七种颜色不同的方块、旋转（含基础墙踢）、软降、硬降、消行、等级加速、下一个预告、暂存、暂停、游戏结束和重新开始。没有后端。界面是简体中文，最高分保存在本机 `localStorage`。

## 运行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

打开终端里显示的本地地址。开发服务器默认是 [http://127.0.0.1:43173](http://127.0.0.1:43173)。

## 操作

| 按键 | 作用 |
| --- | --- |
| ← → | 左右移动 |
| ↑ | 顺时针旋转 |
| ↓ | 软降 |
| 空格 | 硬降 |
| C | 暂存 |
| P | 暂停 |

窄屏和触控设备使用棋盘下方的按钮：左、右、旋转、软降、硬降、暂存、暂停。按住左右和软降会连续移动。

切到别的标签页时，进行中的游戏会自动暂停。

## 规则

- 方块用 7-bag 随机：每七次出现一轮，七种各一次。
- 软降每格 1 分，硬降每格 2 分。
- 消行分数按当前等级倍增：1 行 100、2 行 300、3 行 500、4 行 800。
- 每消除 10 行升 1 级。等级越高，自动下落越快（每级变为上一级间隔的 0.8，最快 80 毫秒）。
- 每锁定一个方块只能暂存一次。暂存格在用过之后会变淡。

## 测试与静态构建

```bash
npm test
npm run build
npm run preview
```

`npm test` 在没有浏览器的情况下检查移动、墙踢、消行计分、升级、暂存、暂停和游戏结束。`npm run build` 会在 `dist/` 生成可部署的静态文件。

## GitHub Pages

推送到 `main` 时，`.github/workflows/pages.yml` 会用 `GITHUB_PAGES=true` 构建。这时 Vite 的 `base` 是 `/tetris-game/`，对应 `https://<用户名>.github.io/tetris-game/`。本地 `npm run dev` 仍使用相对路径。页面的 `<meta name="robots" content="noindex, nofollow">` 要求搜索引擎不要收录。
